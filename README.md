# XV6 Process Scheduler

📄 **Spanish version:** [README_ES.md](README_ES.md)

## Overview

This project explores process scheduling mechanisms in the **XV6 RISC-V** operating system through scheduler analysis, kernel modifications, and performance evaluation.

The project includes the implementation of a **priority-based scheduling policy**, benchmarking of **CPU-bound** and **I/O-bound** workloads, and analysis of **context switching**, **quantum size**, and **starvation scenarios**.

Developed as part of the **Operating Systems** course at the **Faculty of Mathematics, Astronomy, Physics and Computing (FaMAF)**, **National University of Córdoba (UNC)**.

---

## Features

* Analysis of the default **Round Robin scheduler** used by XV6.
* Implementation of a custom **priority-based scheduler**.
* Study of process states and context-switching mechanisms.
* Benchmarking of CPU-bound and I/O-bound workloads.
* Evaluation of different quantum sizes and their impact on performance.
* Starvation analysis under priority scheduling.
* Performance comparison between scheduling policies.
