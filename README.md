XV6 Process Scheduler

Spanish version: [README_ES.md](README.md)

Overview

This project explores process scheduling mechanisms in the XV6 RISC-V operating system through scheduler analysis, kernel modifications and performance evaluation.

The project includes the implementation of a priority-based scheduling policy, benchmarking of CPU-bound and IO-bound workloads, and analysis of context switching, quantum size and starvation scenarios.

Developed as part of the Operating Systems course at FaMAF (Faculty of Mathematics, Astronomy, Physics and Computing), National University of Córdoba (UNC).

Features
Analysis of the default XV6 Round Robin scheduler
Custom priority-based scheduling implementation
Process state and context-switch management
CPU-bound and IO-bound workload benchmarking
Quantum size evaluation
Starvation analysis
Performance comparison between scheduling policies
